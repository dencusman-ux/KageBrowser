# KageBrowser v0.4.6 (Beta)

**KageBrowser** — это легковесный, быстрый и приватный веб-браузер с кастомным графическим интерфейсом в темных тонах, построенный на базе языка **Python 3.12** и фреймворка **PyQt6**. 

Приложение ориентировано на повышенную конфиденциальность и распространяется в виде готового автономного исполняемого файла (**standalone .exe**).

---

## 🚀 Ключевые возможности (Features)

* **Приватность «из коробки» (Zero-Trace):** Браузер работает в режиме повышенной конфиденциальности по умолчанию. В нем полностью отсутствует логирование истории посещений, что делает каждую сессию изолированной и безопасной (почти).
* **Кастомный анимированный UI/UX:** 
  * Индивидуальная реализация вкладок (`ChromeTabBar`) с плавными анимациями открытия, закрытия и адаптивного изменения ширины.
  * Панель вкладок поддерживает быстрое скрытие/отображение по горячим клавишам для максимального погружения в контент.
* **Встроенный AdBlock (Фильтрация трафика):**
  * Модуль `AdBlockInterceptor` перехватывает сетевые запросы «на лету» и блокирует известные рекламные хосты, трекеры и системы аналитики (Google Analytics, DoubleClick, Facebook Pixel и др.).
* **Менеджер загрузок (Downloads Manager):**
  * Всплывающий анимированный оверлей `KageDownloadsPopup` для отслеживания текущих загрузок в реальном времени.
  * Возможность кастомного выбора директории сохранения файлов и быстрого перехода к скачанному файлу или содержащей его папке в проводнике.
* **Интерактивный индикатор масштаба (Zoom Toast):**
  * Плавное отображение текущего уровня масштабирования страницы с помощью геометрического виджета-тоста `KageZoomToast`.
* **Локализация контекстного меню:**
  * Полная русификация и переработка стандартного контекстного меню Chromium (`RU_TRANSLATIONS`) с интеграцией кастомных векторных SVG-иконок.
* **Кастомная стартовая страница:**
  * Встроенная минималистичная домашняя страница со встроенным быстрым переключением поисковых систем (DuckDuckGo, Google, Reddit, GitHub, YouTube) и менеджером быстрых ярлыков (Shortcuts), сохраняющихся в `localStorage`.

---

## 🛠 Стек технологий (Tech Stack)

* **Language:** Python 3.12
* **GUI Framework:** PyQt6 (QtWidgets, QtGui, QtCore)
* **Browser Engine:** QtWebEngineCore, QtWebEngineWidgets (Chromium backend)
* **Graphics & Icons:** Векторный рендеринг динамических иконок на базе `QSvgRenderer`
* **Distribution:** Сборка в независимый исполняемый `.exe` файл (Production Build)

## 🔧 Публикация и запуск (Distribution)

Проект компилируется в бинарный файл для операционной системы Windows. Пользователю не требуется устанавливать интерпретатор Python и сторонние библиотеки.

Для сборки `.exe` файла из исходников используется команда:
```bash
pyinstaller --noconsole --onefile --add-data "kagebrowser_logo.ico;." main.py
```
